An immersive, browser-based 3D tactical First-Person Shooter (FPS) built with **Three.js** for 3D rendering and **Tone.js** for interactive procedural audio synthesis.

🎮 **[Play Live in Browser](https://warlord-game.vercel.app)**

---

## ✨ Features

- 🌐 **Full 3D Environment**: Built from scratch using Three.js with dynamic lighting, shadows, and textures.
- 🎯 **Tactical Gunplay**: Dynamic crosshairs, ADS (aim down sights), weapon sway, recoil mechanics, and hit markers.
- 🔊 **Procedural Audio**: Real-time sound effects for firing, reload, impacts, and footsteps synthesized with Tone.js (no bulky external audio files).
- ⚡ **Zero Dependencies / No Install**: Runs 100% client-side in any modern web browser with WebGL support.
- 📱 **Responsive HUD**: Custom cyber-tactical interface styled with Tailwind CSS.

## 🕹️ Controls

| Action | Key / Input |
|---|---|
| **Move** | W, A, S, D |
| **Look / Aim** | Mouse |
| **Fire** | Left Click |
| **Aim Down Sights (ADS)** | Right Click |
| **Reload** | R |
| **Jump** | Space |
| **Sprint** | Shift |

---

## 🛠️ Tech Stack

- **3D Graphics Engine**: [Three.js](https://threejs.org/) (WebGL)
- **Audio Synthesis**: [Tone.js](https://tonejs.github.io/)
- **UI & HUD Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Core Language**: Vanilla JavaScript (ES6+), HTML5 Canvas

---

## 🚀 Quick Start (Local Run)

No build tools or npm installs needed:

1. Clone the repository:
   ``bash
   git clone https://github.com/saptak69/warlord-game.git
   cd warlord-game
   ``
2. Open index.html in your browser, or run a local server:
   ``bash
   npx serve .
   ``
